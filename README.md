# Power Outage Map

An unofficial static site that plots significant power outages on an [OpenStreetMap](https://www.openstreetmap.org/copyright) basemap and lists them in a sortable table.

This is not an official government or utility outage map. Confirm any outage with the local utility.

## Files

- `data.json` — the source of truth. It holds the `as_of` timestamp and the `outages` array.
- `build.py` — renders `data.json` into crawlable static HTML and SEO files. Run it after every data change.
- `index.html` — homepage and Leaflet map. Regions between `build:` markers are generated; edit layout outside them only.
- `site.css` — shared styles for all pages.
- Generated by `build.py` (commit them, never hand-edit): the static table and meta tags in `index.html`, per-country pages (`/us/`, `/ukraine/`, `/cuba/`, …), `sitemap.xml`, `robots.txt`, `og-image.png`, and `favicon.png`.

## Updating the data

1. Edit `data.json`.
2. Run the build from the repository root:

   ```bash
   python3 build.py
   ```

3. Commit and push everything that changed (`git add -A`).

The build needs Python 3.9+ and Pillow (`pip install pillow`) for the share image. Country pages are created or removed automatically based on the rows in `data.json`.

In the browser, the homepage still fetches `data.json` with a cache-busting query string and reloads it every five minutes. Search engines and visitors without JavaScript see the static snapshot from the last build.

Refresh cadence for the data itself:

- United States: every 30 minutes
- Worldwide list: a few times a day (about four)

Set `as_of` to the snapshot time in Central Time (CT), for example `"2:35 PM CT, Thursday, November 12, 2026"`.

Each object in `outages` should use these fields (leave a value blank when it is unknown — do not invent numbers):

| Field | Meaning |
| --- | --- |
| `lat`, `lon` | Approximate coordinates. Use `null` for nationwide totals that should appear in the table but not as a single map dot. |
| `place` | Location name |
| `region` | Broader area or country |
| `cause` | Why the outage or shortfall is happening |
| `affected` | Customers out, MW shortfall, or a short qualitative note |
| `start` | When it began, if known, with a timezone label if it is not CT |
| `etr` | Estimated restoration time, if the source gives one |
| `source` | A URL to the report or tracker used for that row |
| `updated` | When that row's source was checked or last updated, in CT when practical |

## Preview locally

The page loads `data.json` with `fetch`, so it needs to be served over HTTP (opening the HTML file directly will not load the data).

```bash
cd power-outage-map
python3 -m http.server 8080
```

Then open <http://localhost:8080/>.

## GitHub Pages

The site is served from the `main` branch root at <https://blackoutsmap.com>. The GitHub Pages project URL redirects there. If the custom domain changes, update `SITE_BASE` in `build.py` and the `CNAME` file, then rebuild so canonical URLs, the sitemap, and social tags stay in sync.

Leaflet is loaded from the unpkg CDN. Map tiles come from OpenStreetMap and must keep the attribution shown in the footer and on the map.
